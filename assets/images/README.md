# Property photos

Put real FF Relaxhouse photos in this folder using these exact filenames, then list
each uploaded filename in `photos` inside `assets/js/config.js`.

| Filename          | Where it appears        | Suggested shape        |
|-------------------|-------------------------|------------------------|
| `hero.jpg`        | Top of the home page    | Landscape, about 5:4   |
| `bedroom.jpg`     | Gallery                 | Landscape, 4:3         |
| `living-area.jpg` | Gallery                 | Landscape, 4:3         |
| `kitchen.jpg`     | Gallery                 | Landscape, 4:3         |
| `bathroom.jpg`    | Gallery                 | Landscape, 4:3         |
| `pool.jpg`        | Gallery                 | Landscape, 4:3         |
| `gym.jpg`         | Gallery                 | Landscape, 4:3         |
| `building.jpg`    | Gallery                 | Landscape, 4:3         |

Guidelines:

- Use only genuine photos of the unit and building. Do not use stock photos.
- Resize to about 1600 px on the long edge and keep each file under roughly 300 KB.
- Check each photo for anything private before uploading: unit number, door lock,
  access card, parking bay number, guests' faces, car plates, documents.
- Any photo not listed in `config.js` simply shows a neutral placeholder.
